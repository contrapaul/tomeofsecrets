# Fonts

Self-hosted, all SIL Open Font License.

| File | Family | Range | Use |
|---|---|---|---|
| `Cinzel.woff2` | Cinzel (variable) | wght 400–900 | Wordmark, titles, card names |
| `Alegreya.woff2` | Alegreya (variable) | wght 400–900 | Body, card text, dialogue |
| `Alegreya-Italic.woff2` | Alegreya Italic (variable) | wght 400–900 | Flavour text |
| `JetBrainsMono-Regular.woff2` | JetBrains Mono | 400 | Dev readouts only |

Latin subset only. Declared in `index.html`; loaded before the first scene by
`src/app/fonts.ts`.
